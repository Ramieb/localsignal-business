# LocalSignal

A responsive, static website for LocalSignal, built with HTML, CSS, and vanilla JavaScript.

## Preview locally

Open `index.html` in a browser, or run `npx serve .` from this directory.

## Publish with GitHub Pages

In the repository settings, select **Pages → Build and deployment → Source: GitHub Actions**. Then push `main`; the workflow in `.github/workflows/pages.yml` deploys the repository root to GitHub Pages on each push. The deployment URL will appear in the Pages settings and the workflow run.

## Before launch

- Confirm the positioning and copy fit the business.
- Confirm the published contact inbox is monitored.
- Connect a custom domain and add domain verification records if desired.
